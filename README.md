# Project Websites

Selected research projects:

- [**VGGT-Diff**](https://chenkangjie1123.github.io/VGGT-Diff/) — A geometry-routed multi-view diffusion model that combines VGGT visual geometry with video diffusion for sparse-view novel view synthesis.
- [**Co-Adaptation of 3DGS**](https://chenkangjie1123.github.io/Co-Adaptation-3DGS/) — Quantifies Gaussian co-adaptation in sparse-view 3DGS and alleviates it with lightweight dropout and opacity-noise regularization.
- [**SLGaussian**](https://chenkangjie1123.github.io/SLGaussian/) — A feed-forward method that constructs open-vocabulary 3D semantic fields from two sparse views without per-scene optimization.
